# lila's stylesheets, fonts, and images

These are built from [lila](https://github.com/lichess-org/lila), the software behind lichess.org,
at commit 27ffc8b, by `scripts/buildLilaCss.ts`, which says how to build them again. They're
only files with free licences, which lila's
[COPYING.md](https://github.com/lichess-org/lila/blob/27ffc8b5f296d180e7a648d6bfdad27eef3f86a2/COPYING.md)
lists as follows:

| Files | Authors | Licence |
|---|---|---|
| `css/`, compiled from lila's stylesheets | the lila authors | AGPL-3.0-or-later |
| `font/lichess.woff2`, lila's icons | Dave Gandy, Webalys, Zurb, and others | OFL-1.1, MIT, CC-BY-3.0, and AGPL-3.0-or-later |
| `font/lichess-chess.woff2`, chess figurines | the pgn4web authors | GPL-2.0-or-later |
| `font/noto-sans-*.woff2`, Noto Sans | Google | Apache-2.0 |
| `font/roboto-*.woff2`, Roboto | Christian Robertson | Apache-2.0 |
| `font/racer-car.woff2`, `font/storm.woff2` | the lila authors | AGPL-3.0-or-later |
| `images/board/brown.png` | the lila authors and pirouetti | AGPL-3.0-or-later |
| `piece/cburnett/` | Colin M.L. Burnett | GPL-2.0-or-later |
| `piece/mono/` | Thibault Duplessis and Colin M.L. Burnett | GPL-2.0-or-later |
| `video/`, the analysis settings' help videos | the lila authors | AGPL-3.0-or-later |

The licences' texts are in `LICENSES/`, except the AGPL's, which is the repository's own
[LICENSE](../../LICENSE). For the MIT-licensed icons in `font/lichess.woff2`, the copyright
holders are the authors lila's COPYING.md lists for that file.
